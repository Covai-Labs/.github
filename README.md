## 🛡️ Core Principles

- **🔒 100% Local-First Execution**: All extraction, parsing, DOM traversal, and markdown formatting execute inside the client browser and local services. Zero remote code execution.
- **🚫 Zero Telemetry & Zero Trackers**: No background telemetry beacons, no third-party logging, and no unsolicited outbound network calls.
- **🧩 Decoupled & Resilient Architecture**: Rather than maintaining separate, brittle scraping scripts across multiple extensions, our parsing engine is centralized in [`decant-core`](https://www.npmjs.com/package/decant-core) — fix platform changes once, and the entire ecosystem benefits.
- **⚡ Browser-Assisted Discovery**: Zero-token scraping that runs inside authentic browser sessions, bypassing datacenter IP blocking, CAPTCHAs, and unnecessary LLM token burn.
- **📚 Frictionless PKM & Workflow Integration**: Designed from the ground up to output structured data ready for your Personal Knowledge Management workflows (Obsidian, Logseq, Notion, Bear, NotePlan) and streamlined career pipelines.
