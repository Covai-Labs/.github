## 👋 Hey there!

I'm an independent developer trying hard to build useful things, stay afloat, and contribute honestly to the open-source community.

Covai Labs isn't a large company or venture-backed startup — it's just my personal workshop where I build tools to scratch my own itches. I build mostly local-first browser extensions, extraction engines, and developer utilities that respect your privacy and don't lock your data behind monthly subscriptions or third-party servers.

If any of these tools save you time or help your daily workflow, that makes the effort worthwhile.

## 💡 How I Build

- **Your data stays yours**: Everything runs locally in your browser or machine. No hidden analytics, no telemetry trackers, no phone-home servers.
- **Solving real annoyances**: If I build something, it's usually because existing tools are bloated, behind paywalls, send private data to clouds, or break every other week.
- **Fix once, share freely**: Shared packages like `decant-core` are open-source so other developers don't have to keep reverse-engineering AI DOMs in isolation.
